# Student Management System (Procedure-Oriented)

## Description
A procedure-oriented Student Management System developed in Python to practice core programming concepts.

## Features
- Add student
- View students
- Search student
- Update student
- Delete student
- Store data in a text file

## Technologies Used
- Python 3
- File Handling
